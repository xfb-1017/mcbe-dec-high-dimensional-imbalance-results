# MCBE_DEC numerical results for Expert Systems submission

This repository provides numerical-result files corresponding to the current
manuscript, **Imbalanced classification under high-dimensional distance
concentration: Representative undersampling ensembles via distance-profile
clustering** (10 November 2026 submission snapshot).

Download `MCBE_DEC_current_manuscript_tables_20261110.zip`. It contains:

* `current_tables/`: the exact LaTeX table fragments included in the main
  manuscript and supplementary material. These are the authoritative reported
  numerical summaries for this manuscript snapshot.
* `figure_exports/`: the current external figure PDFs cited by the manuscript.
  Figure 1 is drawn directly in the manuscript LaTeX source.
* `manifest_sha256.csv`: per-file checksums within the archive.

This is the numerical-summary archive for the current manuscript. It contains
the exact reported table fragments and figure exports, but does not contain
raw public benchmark datasets, outer-unit-level logs, raw simulation repeats,
or complete executable analysis code. The public datasets are identified in
the paper; analysis code is available from the authors upon request.

Earlier source bundles from successive analysis rounds are intentionally
excluded because some contain values superseded in the current manuscript.

The repository is intended to accompany the cited manuscript version. If
the manuscript or reported tables change, the archive should be versioned
accordingly.
